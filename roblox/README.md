## How to Upload

1. Open **Roblox Studio**
2. Go to **Avatar** > **Shirts**
3. Click **Create a Shirt**
4. Upload each `.png` file from the `shirts/` folder
5. Name it something catchy (use the design name)
6. Add a description with keywords like "meme", "funny", "roblox"
7. Set price: **10-50 Robux** (start low, raise if popular)
8. Click **Publish**
9. Repeat for all 24 shirts

## Pricing Strategy

- **Start at 10 Robux** — gets more sales, builds reputation
- **Raise to 25-50 Robux** once you get reviews
- **Bundle deals** — sell 3 for 20 Robux
- **Seasonal** — holiday themed shirts sell more
