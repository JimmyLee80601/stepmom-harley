# Step-Aunt Harley 💕

A complete on-device AI step-aunt package for Trystan's REVVL 5G tablet.

## What's This?

A free, fully offline AI chat app that runs right on your Android tablet.
No internet needed. No server. No data leaves your device. Just you and your
step-aunt Harley chatting.

## Quick Start

1. Copy all files from USB drive to tablet
2. Install `ChatterUI.apk`
3. Load `qwen2.5-1.5b-instruct-q4_k_m.gguf` in ChatterUI
4. Set the system prompt from `system_prompt.txt`
5. Start chatting!

See `SETUP.md` for detailed instructions.

## What's in the Package

| File | Size | Purpose |
|------|------|---------|

## Requirements

- Android 7.0+ (API 24)
- 3GB free RAM (tablet has 6GB)
- About 1.2GB storage
